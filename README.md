# Contrato de Estética

Formulário digital para contrato de prestação de serviços estéticos, com foto do paciente, assinatura e geração de PDF.

## Uso local

Abra `index.html` no navegador ou sirva com:

```bash
npx serve .
```

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (ex.: `contrato-estetica`)
2. Envie este projeto:

```bash
git init
git add index.html README.md
git commit -m "Publica formulário de contrato estético"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/contrato-estetica.git
git push -u origin main
```

3. No GitHub: **Settings → Pages → Source: Deploy from branch → branch `main` → folder `/ (root)` → Save**
4. Acesse em: `https://SEU_USUARIO.github.io/contrato-estetica/`

> Com HTTPS ativo, a câmera do celular funciona corretamente.
